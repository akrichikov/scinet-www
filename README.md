scinet-www
This is a Next.js project bootstrapped with create-next-app, configured with TypeScript, Tailwind CSS, and Turbopack.
Getting Started
First, ensure all dependencies are installed:
npm install

Then, run the development server with Turbopack on port 8022:
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev

Open http://localhost:8022 in your browser to see the result. The server is also accessible on the network at http://75.119.153.32:8022 (adjust the IP if needed for your environment).
You can start editing the page by modifying src/app/page.tsx. The page auto-updates as you edit the file.
This project uses next/font to automatically optimize and load Geist, a new font family for Vercel.
Project Configuration

Next.js Version: 15.3.2 with Turbopack enabled
Dependencies: React 19.1.0, Tailwind CSS 4, TypeScript 5
Experimental Features: Server actions enabled, React Compiler disabled
Port: Runs on 8022 by default (configurable in package.json)
